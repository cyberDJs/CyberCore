## Goal

LG-0001 without granting provider content authority or adding provider/network/write nodes.

## Change unit

Problem: LG-0001 accepts already-normalized `SourceSnapshot.authority`, so a caller could assign
authority without provenance binding.

Beneficiary: CASER-SOURCER and future provider adapters.

Expected improvement: provider observations become authority-free inputs; trusted exact-match
bindings assign authority, emit provenance, and fail closed when identity/authority is unresolved.

## Security / privacy boundary

- No private Google Drive IDs are committed; repository examples use placeholders only.
- No credentials, cookies, authorization headers, or arbitrary locator keys are accepted into
  provenance.
- A synthetic `token=plaintext-credential` test proves unsafe locator keys fail closed before
  provenance capture; it is test data, not a credential.
- Facts are required to be normalized, sanitized, and secret-free by the trusted adapter before
  graph invocation because fact values may appear in reconciliation findings.
- No network/provider calls are added to the graph.
- No write/remediation/deployment node is added.
- No checkpoint persistence, production mutation, or external-provider mutation is in scope.
