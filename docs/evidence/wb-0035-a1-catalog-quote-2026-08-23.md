## Parser corrections discovered by live provider behavior

### KVM catalog price field

The original A1 parser incorrectly treated `vpsNyCost` as the KVM slice price. The authenticated catalog demonstrates:

```text
vpsSliceKvmLCost = 3
vpsNyCost = 1
```

CyberCore now binds the KVM candidate to `vpsSliceKvmLCost` and keeps `vpsNyCost=1` only as a regression trap in synthetic fixtures.

### Quote OS/version response mapping

The original synthetic quote assumed:

```text
os=ubuntu
version=ubuntu24
```

The live provider response instead uses:

```text
os=ubuntu24
version=ubuntu
```

CyberCore now validates this observed live response mapping explicitly.

### Ephemeral root-password generation

The prior generator used URL-safe random tokens. Those are strong random secrets but do not guarantee that every generated value contains at least one character from each category required by InterServer's VPS-order validator. CyberCore now generates an ephemeral quote-only root password that guarantees:

- at least one lowercase character;
- at least one uppercase character;
- at least one digit;
- at least one provider-compatible special character;
- length well above the 8-character minimum.

The generated value is never written to ordinary evidence.
