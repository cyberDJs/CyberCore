# WB-0028 Concise Summary

Date: 2026-08-19

WB-0028 starts CyberCore self-deployment safely by creating the staging-only boundary before executable automation.

It defines:

- self-deployment architecture;
- InterServer staging target contract;
- runbook;
- ADR candidate;
- evidence receipt contract;
- rollback/effect-verifier expectations;
- explicit stop lines.

It does not deploy anything.
