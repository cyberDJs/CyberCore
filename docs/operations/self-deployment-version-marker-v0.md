# Self-Deployment Version Marker v0

Date: 2026-08-19
Work block: `WB-0028`

## Purpose

A future staging deployment needs a safe way to prove which commit is running.

## Marker contract

The deploy artifact should include a non-secret marker such as:

```json
{
  "repository": "cyberDJs/CyberCore",
  "commit": "<source commit>",
  "branch": "<source branch>",
  "built_at": "<timestamp>",
  "environment": "interserver-shared-hosting-staging"
}
```

## Rules

- Marker must contain no secrets.
- Marker must not expose internal hostnames if they are considered sensitive.
- Effect verifier must compare the marker commit with the deployment manifest commit.
- Missing marker means the deployment cannot be marked `VERIFIED`.

## Current state

Marker is a contract only. It is not yet generated by a build workflow.
