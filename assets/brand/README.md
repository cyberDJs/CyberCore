# CyberCore Brand Assets

Status: active repository identity

These assets are deterministic SVG files intended for repository, documentation,
release-page, and social-preview use.

## Files

| File | Use |
|---|---|
| `cybercore-mark.svg` | Compact icon mark |
| `cybercore-logo.svg` | Core logo lockup for README and docs |
| `cybercore-readme-hero.svg` | Primary README showcase hero |
| `cybercore-capability-map.svg` | README capability overview |
| `cybercore-social-preview.svg` | GitHub social preview or release header |

## Visual direction

The CyberCore visual identity follows the project design-system direction:

- minimalist cyberpunk;
- technical dashboard clarity;
- high contrast without decorative noise;
- dark navy surfaces with cyan, indigo, and magenta semantic accents;
- color used as signal rather than ornament;
- deterministic, reviewable SVG for repository-native presentation.

## Repository presentation rules

- Prefer the README hero over stacking a separate logo, heading, and decorative banner.
- Keep capability visuals consistent with the canonical architecture and project language.
- Social preview copy must stay product-level and must not claim production readiness.
- Funding or sponsor visuals must not imply a payment destination until one is verified.

## Safety rules

- Do not add secrets, screenshots of private infrastructure, customer names, or production topology to public brand assets.
- Prefer SVG for repo-native identity assets so changes remain reviewable.
- Use generated bitmap imagery only when the asset depends on illustration, texture, or photorealistic composition.
